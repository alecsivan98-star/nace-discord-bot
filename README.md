# NACE Discord Bot

Bot Discord pentru onboarding-ul membrilor NACE.

## Funcții

- Trimite automat mesaj de bun venit în DM.
- Prezintă pe scurt proiectul NACE.
- Cere screenshot-ul înregistrării pe NACE.
- Primește screenshot-ul în DM.
- Verifică screenshot-ul.
- După verificare, acordă rolul `Trader`.

## Configurare

Variabilele necesare:

- `DISCORD_TOKEN`
- `GUILD_ID`
- `TRADER_ROLE_ID`
- `NACE_URL`

## Pornire

```bash
npm install
npm start
